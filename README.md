# Mateus Dev — Portfolio
**A personal portfolio built with React and Vite to showcase my projects and front-end development journey.**

## 📌 About the Project
This is my personal space to centralize and demonstrate what I can do. The project goes beyond a simple static page: it brings practical tools from the modern front-end ecosystem to create a smooth, fast, and intuitive experience for visitors.

## 🚀 Features
*   **Dynamic sections:** Simple and direct navigation between my projects and contact information.
*   **Dark/Light Mode:** Theme switching with automatic persistence (saves the user's choice in `localStorage`).
*   **Detailed cards:** Each project has its own description, technology stack, and direct links to the code and deploy.
*   **Preview modal:** More details about each project open directly on the screen without loading a new page.
*   **Functional form:** Message sending integrated with EmailJS, featuring real-time field validation.
*   **Fully responsive:** Interface adapted to work perfectly on both large screens and mobile devices.

## 🛠️ Technology Stack
*   **React 19** & **Vite** (Lightweight, fast, and componentized environment)
*   **JavaScript (ES6+)**
*   **CSS Modules** (Isolated styles per component to avoid conflicts)
*   **EmailJS** (To process contact form submissions directly from the front-end)
*   **ESLint** (Code standardization and quality)

## 💻 Getting Started
### Prerequisites
You will need [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1.  Clone this repository:
```bash
git clone https://github.com/Mateus-henrique17/portifolio.git
```
2.  Change to the project directory and install all dependencies:
```bash
cd portifolio
npm install
```
3.  Start the local development server:
```bash
npm run dev
```
Vite will display the local URL (usually `http://localhost:5173`) to open in your browser.

## ⌨️ Available Scripts
In the `package.json` file, you can find the following utility commands:

| Command | Description |
|---|---|
| `npm run dev` | Starts the project in a local development environment. |
| `npm run lint` | Checks for code formatting or syntax errors. |
| `npm run build` | Creates the optimized production build inside the `/dist` folder. |
| `npm run preview` | Locally previews the final production build. |
| `npm run deploy` | Automatically uploads the `/dist` folder to GitHub Pages. |
